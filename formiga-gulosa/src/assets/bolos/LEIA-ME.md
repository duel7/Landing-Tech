# Fotos dos bolos

Coloque aqui as fotografias reais dos bolos e doces da Formiga Gulosa (JPG, PNG, WebP ou AVIF).
Elas aparecem sozinhas na abertura, no Sobre e no Mostruário depois de `npm run build`.

Nome, categoria, descrição e ordem de cada foto: `src/content/bolos.ts`.
Mais detalhes no README do projeto.
